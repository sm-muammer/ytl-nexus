# YTL Nexus in Kiro

`AGENTS.md` at the repository root is the rule set for this project. Read it at session start if it is not already in context.

## Credit discipline

The owner has a limited credit budget.

- One task per chat. After the end-of-task commit, tell the owner to open a new chat and send: `Continue YTL Nexus: run Task <n>`.
- State the recommended model and effort for the next task (from the task table in `docs/spec/implementation-plan.md`) in the final message.
- If the current model is more expensive than the task needs, say so in one line at the start of the session, then continue.
- Read files with targeted ranges and search before reading. Reuse what `docs/PROGRESS.md` already records instead of re-exploring.
