# Architecture decision records

> **Purpose:** the log of significant technical decisions, why they were made and what they cost.
> **Audience:** builders and future owners deciding whether a decision still holds.

Write a new ADR when a choice is hard to reverse, affects several modules, or departs from the approved plan. Number sequentially, never renumber, and mark replaced ADRs as superseded instead of deleting them.

Template: Status, Date, Context, Decision, Alternatives considered, Consequences.
