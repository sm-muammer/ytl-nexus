# Nexus Shortcuts plugin for Roundcube

Gmail-inspired keyboard shortcuts for Roundcube Webmail on YTL Nexus.
Requirement: `MAIL-07` / `docs/spec/17-nexus-mail.md`.

## Shortcuts

| Key | Action |
| --- | --- |
| `c` | Compose new message |
| `/` | Focus quick search |
| `g` then `i` | Go to Inbox |
| `r` | Reply |
| `a` | Reply all |
| `f` | Forward |
| `e` | Archive message (uses `archive` plugin if active) |
| `#` | Delete message |
| `?` | Open accessible keyboard shortcuts help dialog |

Shortcuts are automatically bypassed when typing in any input field, textarea, select or editable area, or when any modifier key (Ctrl, Alt, Meta) is held.
